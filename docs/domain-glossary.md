# Rilono Domain Glossary

Last updated: 2026-03-25

## Product Terms

`F1 journey stage`
Sequential progress stage in a student's study-abroad journey (for example: getting started, admission received, I-20 received, DS-160 filed, fees paid, visa, ready to fly). The `F1` name is historical; stages now span all five country journeys.

`Document catalog`
The canonical list of supported document types stored in `document_type_catalog`, including labels, ordering, and stage metadata.

`Stage gate`
A rule indicating whether required document evidence exists (and optionally validates) before advancing through a journey stage.

`Stage gate group`
A logical group for alternative document satisfaction, such as `admission_proof` or `financial_proof`.

`Visa case status`
Per-user state such as `new` or `refused` used in profile and guidance context.

`Student profile snapshot`
Structured profile artifact used by AI workflows to reason about user progress and document consistency.

`AI chat upload event`
Tracking row in `rilono_ai_chat_upload_events` linking users and uploaded AI chat attachments.

`Daily AI notification`
A proactive reminder decision generated by AI analysis of profile and extracted document content.

`F1 visa news item`
Normalized news record in `f1_visa_news` shown to users from pre-ingested content.

## Account And Access Terms

`Active user`
A user with `is_active=true`, allowed to authenticate if other checks pass.

`Email verified user`
A user with `email_verified=true`, required for normal login flow.

`Developer email allowlist`
Emails in `developer_emails` that bypass normal university-domain validation checks.

`Admin user`
A user with elevated backend privileges (`is_admin=true`) for protected operations.

`Enterprise credential`
Login identity row in `enterprise_credentials`; synced into `users` for shared auth/session behavior.

`Enterprise organization member role`
Role assigned in enterprise org (`admin`, `editor`, `viewer`) controlling management/edit capabilities.

## Billing And Growth Terms

`Subscription plan`
Current user plan (`free` or `pro`) stored in `subscriptions`.

`Subscription payment status`
Lifecycle state for payment rows (`created`, `verified`, `failed`) in `subscription_payments`.

`Referral code`
Unique user code used to attribute referred signups and referral rewards.

`Coupon code`
Discount code tracked in `coupon_codes` with percentage and optional usage limits.

## Platform Terms

`Artifact encryption`
Encryption for stored artifacts/documents via server key material (`ARTIFACT_ENCRYPTION_KEY` or fallback behavior tied to `SECRET_KEY`).

`Turnstile verification`
Cloudflare challenge verification path used to reduce automated abuse.

`Notification center`
In-app bell notification system stored in `user_notifications` with read/unread state.
